# loader on Lunar translates SRG back to its own names (MappingClassLoader + mappings/*.csv).
# This is the same rename ForgeGradle's "reobf" step does, limited to what we use.
#
# Source of each entry:
#   [meowtils] Meowtils 2.0.1's own compiled code references this exact SRG name (strongest).
#   [csv]      single candidate in Meowtils' bundled mappings/*.csv for that owner.
#   [enum]     enum constants keep their names in SRG.
#
# Adding a member: find its SRG name in libs/meowtils.jar -> meowtils/mappings/fields.csv or
# methods.csv (columns: searge,name,side,...). If several rows share the name, pick the one
# whose owner matches: check how Meowtils' own classes reference it (javap -c on a Meowtils
# class that uses it) or an MCP 1.8.9 stable_22 mapping viewer. Then add the stub member in
# buildtools/stubs with the identical signature.
#
